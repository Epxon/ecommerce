# Menu principal

## Funcionalidad
Menu principal del software, el cual ofrece una amplia variedad de acciones y operaciones que puede realizar el usuario como agregar, eliminar, modificar, visualizar etc.. 

### Elementos graficos utilizados
1. Botones para ejecutar la opcion deseada en el menu
1. Label que funciona como boton de volver a la pestaña inicial
1. Label para la impresion del texto en el menu
1. Panel brillante para mejorar la estetica de la ventana

## Metodos utilizados en esta pestaña
|Metodo| Uso |
|-|-|
| SetIcono | Metodo para relacionar con la clase y ajustar visualmente |
| volver | Metodo para regresar a la pestaña anterior |
