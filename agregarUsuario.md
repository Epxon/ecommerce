# Agregar usuario

## Funcionalidad 
Ventana que permite el registro de un nuevo usuario en el sistema

### Elementos graficos utilizados
* Boton para registrar el usuario
* Label para mostrar texto en la ventana
* TexFields necesarios para capturar la información del nuevo usuario
* Panel brillante para mejorar la estetica de la ventana

## Metodos utilizados 
| Metodo | uso |
|-|-|
| ValidarDatos | Valida que los datos ingresados cumplan los criterios necesarios |
| noRepetir | Valida que el usuario ingresado no este registrado ya en el sistema |
| registrar | Da de alta el usuario y lo agrega a la base de datos |
