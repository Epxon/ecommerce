# Sistema de gestión de un gimnasio

## Objetivo general
Creación de una interface para la administración de un **gimnasio**con una base de datos funcional

### Contenido del proyecto
* Universo del discurso
* Diagrama entidad relación
* Interfaz grafca funcional
* Base de datos desarrollada en SQL

### Materias relacionadas
* Base de datos
* Interacción humano computadora
