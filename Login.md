# Login

## Funcionalidad:
Primera ventana en aparecer al ejecutar el software, permitiendo a la persona el ingreso de un usuario y contraseña para el inicio de sesion al programa, mostrando logos del gimnasio en la parte derecha de la ventana y dando la opción de registrarse en el caso de no contar con una cuenta.

### Elementos graficos utilizados en esta pestaña
1. Botones para iniciar sesion / registrar un usuario
1. Label para la escritura de instrucciones en la pantalla, fondo y proyeccion de imagenes
1. Panel brillante para mejorar la estetica de la ventana
1. password field para seguridad de la contraseña
1. Textfield para el ingreso del usuario

## Metodos utilizados en esta pestaña
|Metodo| Uso |
|-|-|
| ValidarCampos | Metodo que verifica los datos ingresados por el usuario para el inicio de sesión | 
| verificarCredenciales | Muestra un dialog en pantalla mientras se verifican los datos |
| mostrarImagenAleatoria | muestra imagenes cambiantes para un toque estetico |
